Same source records · four different views

Chart 09 design options

These views use published policy details. “Not listed” means the product page is silent; it does not mean the benefit is excluded.

Option 1 · Small multiples

Compare plan status for each benefit

Six panels keep the benefit names visible while showing each plan’s published status.

Option 2 · Stacked bars

Summarise each plan’s listed status mix

Each bar counts how many of the six benefit items fall into each published status.

Option 3 · Monetary dot plots

Compare the published cover limits

Small multiples use the stated ringgit limits. A zero marks an explicit exclusion; no point means no limit was listed.

Option 4 · Bipartite network

Connect plans to their published status mix

Links join each plan to its recorded status; thicker links mean more benefit items in that status.
